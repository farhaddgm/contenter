# برچسب‌ها و کمپین‌ها

برای دسته‌بندی ایده‌ها و محتواهای یک موضوع دو ابزار داریم: **برچسب** (برای هر تعداد ایده یا محتوا، چندتا روی هر مورد) و **کمپین** (هر محتوا حداکثر در یک کمپین است). هر دو **بدون AI** کار می‌کنند و به **همان موضوع** وابسته‌اند؛ پس دسترسی‌شان همان دسترسی موضوع است ([17-project-access.md](17-project-access.md)).

## برچسب (`Tag`)

- هر برچسب مال یک موضوع است: `name` (۱ تا ۴۰ نویسه) و `color` یکی از ۱۰ رنگ ثابت (`TagColor` در `packages/shared`). رنگ در پایگاه داده رشته است و Zod آن را کنترل می‌کند.
- نام در هر موضوع یکتاست و **بدون حساسیت به حروف بزرگ و کوچک** چک می‌شود (تکراری ← ۴۰۹).
- یک ایده یا محتوا تا ۲۰ برچسب دارد (`MAX_TAGS_PER_ITEM`). رابطه‌ها چندبه‌چند و ضمنی‌اند (`_ContentToTag`، `_IdeaToTag`).
- برچسب هرگز از موضوعش بیرون نمی‌رود: `PUT .../tags` اگر شناسهٔ برچسبی از موضوع دیگر باشد، ۴۰۰ می‌دهد.
- حذف برچسب فقط پیوندها را برمی‌دارد؛ ایده‌ها و محتواها می‌مانند.
- محتوایی که از روی یک ایده نوشته می‌شود، **برچسب‌های آن ایده را به ارث می‌برد** (فقط هنگام ساخت).

### در رابط
- تب **«برچسب‌ها و کمپین‌ها»** در صفحهٔ موضوع: ساخت، ویرایش (نام و رنگ) و حذف برچسب، همراه با تعداد استفاده.
- کارت ایده و کارت «سازمان‌دهی» در صفحهٔ محتوا: انتخاب‌گر برچسب. با تایپ نام، اگر وجود نداشته باشد «ساخت و انتخاب» پیشنهاد می‌شود.
- فهرست ایده‌ها و جدول محتواهای موضوع: فیلتر برچسب.

## کمپین (`Campaign`)

- `name` (۲ تا ۱۲۰ نویسه، یکتا در موضوع)، `description`، `status` (`ACTIVE` یا `ARCHIVED`) و `startsAt` / `endsAt` **اختیاری**.
- **کمپین بدون تاریخ همان «مجموعه» است**؛ برای همین جدول جداگانه‌ای برای مجموعه نداریم.
- پایان قبل از شروع پذیرفته نمی‌شود. در ویرایش جزئی، تاریخ تازه با تاریخ ذخیره‌شدهٔ طرف دیگر هم سنجیده می‌شود. مقدار `null` تاریخ را پاک می‌کند.
- محتوا با `PATCH /contents/:id` و `{ campaignId }` به کمپین می‌پیوندد (`null` = بیرون آوردن). کمپین باید مال همان موضوع باشد.
- حذف کمپین محتواها را حذف نمی‌کند؛ فقط از کمپین بیرون می‌آیند (`ON DELETE SET NULL`). کمپین بایگانی‌شده در انتخاب‌گر محتواهای تازه دیده نمی‌شود، ولی محتوایی که از قبل در آن است همچنان آن را نشان می‌دهد.
- کارت هر کمپین به جدول محتواهای موضوع با `?campaign=<id>` پیوند دارد.

## API

| متد | مسیر | توضیح |
|---|---|---|
| GET / POST | `/topics/:id/tags` | فهرست (با `_count.contents` و `_count.ideas`) / ساخت `{ name, color? }` |
| PATCH / DELETE | `/tags/:id` | ویرایش `{ name?, color? }` / حذف |
| PUT | `/contents/:id/tags` | `{ tagIds }` ← جایگزینی همهٔ برچسب‌های محتوا |
| PUT | `/ideas/:id/tags` | `{ tagIds }` ← جایگزینی همهٔ برچسب‌های ایده |
| GET / POST | `/topics/:id/campaigns` | فهرست (با `_count.contents`) / ساخت `{ name, description?, startsAt?, endsAt? }` |
| PATCH / DELETE | `/campaigns/:id` | ویرایش (شامل `status`) / حذف |
| GET | `/contents?tagId&campaignId` · `/topics/:id/ideas?tagId` | فیلتر فهرست‌ها |

محتوا و ایده در پاسخ فهرست و جزئیات، `tags` و (برای محتوا) `campaign` دارند. روت‌ها با `@TopicScoped('tag' | 'campaign' | 'content' | 'idea')` محافظت می‌شوند؛ نوشتن به دسترسی «ویرایش» نیاز دارد.

لاگ ممیزی: `tag.create|update|delete`، `campaign.create|update|delete`، `content.tags`، `idea.tags`.
