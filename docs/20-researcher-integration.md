# اتصال فقط‌خواندنی Bee Researcher

این مصرف‌کننده از Docoo مستقل است؛ هیچ مسیر، توکن یا مجوز Docoo تغییر نمی‌کند. همهٔ مسیرها زیر `/api/integrations/researcher` هستند و فقط GET دارند.

- `RESEARCHER_INTEGRATION_TOKEN`: رمز مستقل، حداقل ۳۲ نویسه؛ نباید با `INTEGRATION_TOKEN` یکسان باشد.
- `RESEARCHER_BUSINESS_ACCESS`: پیش‌فرض امن `selected`؛ برای نیاز تأییدشدهٔ این پروژه مقدار `all` تنظیم می‌شود. در حالت `all` تمام کسب‌وکارهای فعلی و آینده بدون تغییر تنظیمات در Researcher قابل جست‌وجو و انتخاب هستند؛ هیچ پروژه‌ای خودکار متصل نمی‌شود.
- `RESEARCHER_BUSINESS_IDS`: فقط در حالت `selected`، شناسه‌های مجاز جداشده با ویرگول؛ پیش‌فرض خالی یعنی هیچ کسب‌وکاری. wildcard به‌عنوان شناسه پذیرفته نمی‌شود.
- `GET /ping`: قرارداد نسخهٔ ۱ و شمار کسب‌وکارهای مجاز.
- `GET /businesses?q&page&pageSize`: فهرست صفحه‌بندی‌شدهٔ مجاز.
- `GET /businesses/{id}/export`: همان قرارداد خروجی مستند در docs/18؛ فقط برای شناسهٔ مجاز. درخواست شناسهٔ ناموجود یا غیرمجاز ۴۰۴ می‌دهد.

بدون رمز تنظیم‌شده همهٔ مسیرها ۴۰۴ هستند؛ رمز نامعتبر ۴۰۱. مقایسه زمان‌ثابت است و نرخ درخواست ۱۲۰ در دقیقه. دریافت خروجی با `integration.researcher_export` ثبت می‌شود. فایل‌ها، اشخاص و اعتبارنامه‌ها صادر نمی‌شوند. دسترسی عادی حساب‌های Contenter از این توکن سرویس مستقل است؛ Researcher باید مجوز پروژه را خودش اعمال کند. انتخاب کسب‌وکار فقط برای مالک یا مدیر دارای مجوز نوشتن پروژه است؛ کاربران فقط‌خواندنی فهرست سراسری را نمی‌بینند. تغییر دامنهٔ دسترسی و توکن deployment-managed و مخصوص مالک سرور است.

در مرحلهٔ فعلی Researcher پروفایل را برای مشاهده و همگام‌سازی ذخیره می‌کند؛ **استفاده در امتیازدهی/تحلیل AI عمداً غیرفعال و خارج از محدوده است.**

آزمون‌های الزامی: جدایی دو توکن، خاموش بودن پیش‌فرض، allowlist خالی، جلوگیری از export غیرمجاز در حالت selected، شناسایی کسب‌وکار جدید بدون تغییر تنظیمات در حالت all، پالایش لیست و شمارش، قرارداد خروجی و عدم تغییر API Docoo. انتشار باید افزایشی و بدون migration Contenter باشد. هیچ اتصال مستقیم به DB Contenter لازم نیست.
